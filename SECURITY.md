# Security

The package contains agent instructions and optional local Node helpers. It bundles no MCP server, credentials, telemetry, browser binary or updater. Execution access depends on the host's tools, permissions and installed libraries.

The installer writes to the selected skill location and its backup/staging locations. The browser helper uses an existing library/browser and an explicitly supplied URL. Use authorized test data; keep authentication state, private page output and secrets out of public reports.

## Reporting

Use GitHub **Security → Report a vulnerability** for a private report. Provide the revision, minimal reproduction and impact. If private reporting is unavailable, open an issue requesting a private contact without disclosing the vulnerability itself. Do not post credentials or private exploit data.

There is no guaranteed response time or formal long-term support policy. Fixes target the latest maintained version. Ordinary bugs belong in public issues.
