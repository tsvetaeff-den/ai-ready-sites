# AI-Ready Sites 0.3.0

[Русская версия](0.3.0.ru.md)

AI-Ready Sites now includes self-contained guidance for website copy, product instructions, technical documentation and RU/EN editing and translation. It preserves factual conditions, commands, URLs and actual UI labels while improving readability. Text-only requests stay scoped to text.

## Changes

- Three internal guides: site/interface copy, technical writing, and editorial review/translation.
- Complete English and Russian README with installation, usage, prerequisites and limitations.
- Eight reviewed RU/EN editing cases and six automated corruption controls. Two semantic discrepancies found during review were corrected; the evaluation records them.
- Ten pinned sources with retained licenses. No other skills or external scanners are required.
- GitHub Actions checks package integrity, isolated installation and saved bilingual artifacts on Ubuntu, Windows and macOS with Node.js 24.

## Install or upgrade

1. Download ai-ready-sites-0.3.0.zip and ai-ready-sites-0.3.0.sha256 from this release.
2. Verify SHA-256 using the command for your platform in the README, then extract the ZIP.
3. From the extracted ai-ready-sites directory, run the command below. Node.js 18 or later is required for the installer.

```text
node scripts/install.mjs
```

To replace an existing different installation while preserving a backup outside the active skills directory:

```text
node scripts/install.mjs --replace
```

Alternatively, copy the complete skills/ai-ready-sites folder into your user skills directory, preserving the previous installation outside active discovery first. Manual copying does not require Node.js. Choose one installation route and open a new Codex chat after installation.

## Verification and limits

The installation archive is built from the release commit, extracted and checked before upload. Its contents are verified by a fresh isolated installation. The published assets are downloaded again and compared with the local checksum. The release is published only after all three platform jobs pass for that commit.

Saved-artifact checks do not run a model or prove semantic equivalence. The editorial review is documented separately. Browser verification needs an available host browser tool or runtime; no new full website/browser, physical-device or screen-reader evaluation is claimed in this release. Minimum Node.js 18 execution was not tested; automated platform checks use Node.js 24. Internal skill instructions and original license texts remain English. Original work is Apache-2.0, with third-party notices retained.
