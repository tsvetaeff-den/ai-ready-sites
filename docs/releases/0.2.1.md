# AI-Ready Sites 0.2.1

This patch release fixes installation with newer Node.js versions and provides a portable, checksummed package.

## Changes

- Copy the skill into a new child of the temporary staging directory, avoiding ERR_FS_CP_EEXIST on current Node.js.
- Keep strict copy verification, refusal to silently overwrite, exact backups on replacement, and cleanup of temporary staging directories.
- Synchronize plugin, skill, installer and provenance version metadata.
- Add GitHub Actions validation on Ubuntu, Windows and macOS with Node.js 24.

## Install

1. Download ai-ready-sites-0.2.1.zip and ai-ready-sites-0.2.1.sha256 from this release.
2. Verify SHA-256 and extract the ZIP.
3. From the extracted ai-ready-sites directory, run node scripts/install.mjs, or copy the complete skills/ai-ready-sites directory into your Codex user skills folder.
4. Open a new Codex chat and request $ai-ready-sites.

For an existing different installation, use node scripts/install.mjs --replace to preserve a backup and install this version. Identical content is a no-op. Choose one skill/plugin installation route to avoid duplicates.

## Validation and scope

The exact release commit must pass all three GitHub Actions platform jobs before publication. The ZIP is extracted and its validator/installer tests run before upload. A checksum accompanies the archive.

No other skills, external design engine, account or API key is required by this skill. Actual browser checks still need an available browser tool/runtime. This release does not claim full browser or accessibility verification on every platform. The Apache-2.0 license and third-party notices are retained.
