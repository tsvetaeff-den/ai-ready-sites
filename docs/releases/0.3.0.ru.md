# AI-Ready Sites 0.3.0

[English version](0.3.0.md)

В AI-Ready Sites добавлены самостоятельные руководства по текстам сайтов, инструкциям для пользователей, технической документации, редактуре и переводу RU/EN. Редактура улучшает читаемость, сохраняя факты, условия, команды, ссылки и реальные названия элементов интерфейса. Для работы только с текстом не требуется проходить разработку сайта.

## Изменения

- Три внутренних руководства: тексты сайтов и интерфейсов, техническая документация, редактура и перевод.
- Полный README на русском и английском с установкой, использованием, требованиями и ограничениями.
- Восемь проверенных сценариев RU/EN и шесть автоматических проверок на намеренно испорченных примерах. Две найденные при редакторской проверке смысловые неточности исправлены и описаны в отчёте.
- Десять закреплённых источников с сохранёнными лицензиями. Другие скиллы и внешние сканеры не требуются.
- GitHub Actions проверяет целостность пакета, установку в отдельную папку и сохранённые двуязычные результаты в Ubuntu, Windows и macOS с Node.js 24.

## Установка и обновление

1. Скачайте ai-ready-sites-0.3.0.zip и ai-ready-sites-0.3.0.sha256 со страницы релиза.
2. Проверьте SHA-256 командой для вашей системы из README и распакуйте ZIP.
3. Из распакованного каталога ai-ready-sites выполните команду ниже. Для установщика требуется Node.js 18 или новее.

```text
node scripts/install.mjs
```

Чтобы заменить отличающуюся установленную версию, сохранив резервную копию вне активной папки навыков:

```text
node scripts/install.mjs --replace
```

Другой способ — скопировать всю папку skills/ai-ready-sites в пользовательскую папку навыков, предварительно сохранив существующую установку вне каталогов активного обнаружения. Для ручного копирования Node.js не требуется. Выберите один способ установки и откройте новый чат Codex после её завершения.

## Проверки и ограничения

Установочный архив создаётся из коммита релиза, распаковывается и проверяется до загрузки. Содержимое сверяется после новой установки в отдельную папку. Опубликованные файлы скачиваются повторно и сравниваются с локальной контрольной суммой. Релиз публикуется только после успешных проверок этого коммита во всех трёх системах.

Проверки сохранённых результатов не запускают модель и не доказывают смысловую эквивалентность; редакторская проверка описана отдельно. Для проверки сайта в браузере нужен доступный браузерный инструмент или среда автоматизации. Новая полная проверка сайтов, физических устройств и экранного диктора в этом релизе не заявляется. Выполнение на минимальной Node.js 18 не проверялось; автоматические проверки используют Node.js 24. Внутренние инструкции скилла и оригинальные тексты лицензий остаются на английском. Оригинальные материалы распространяются по Apache-2.0, уведомления сторонних авторов сохранены.
