# AI-Ready Sites

[English version](README.md)

[![Validate](https://github.com/tsvetaeff-den/ai-ready-sites/actions/workflows/validate.yml/badge.svg)](https://github.com/tsvetaeff-den/ai-ready-sites/actions/workflows/validate.yml)

Самодостаточный навык для проектирования, разработки, улучшения и проверки сайтов и веб-интерфейсов. Его можно использовать для нового лендинга, существующего интерфейса продукта, небольшой правки, аудита или проверки готовности к выпуску. Он начинает с запрошенного этапа и учитывает инструменты и правила проекта.

**Версия:** 0.3.0. В релиз входят внутренние руководства по редактуре, технической документации, текстам сайтов и интерфейсов, а также переводу между русским и английским.

## Что потребуется

Модель и инструменты работы с кодом предоставляет приложение, в котором используется навык. Сам навык содержит руководства по дизайну, реализации, качеству и проверке в браузере. Для него не нужны другой навык, глобальный `AGENTS.md`, внешний инструмент проектирования, аккаунт хостинга, платный API или определённый фреймворк.

- **Для копирования и использования навыка:** приложение, способное загрузить папку навыка. Node.js не требуется.
- **Для необязательного установщика:** Node.js 18 или новее.
- **Для проверки сайта в браузере:** доступный инструмент управления браузером в приложении либо установленная среда автоматизации с браузером. Отсутствие браузерных инструментов указывается как ограничение проверки.

Пользовательский README поддерживается на русском и [английском](README.md); обе версии описывают один релиз. Внутренние инструкции и код написаны на английском; модель можно попросить работать на удобном вам языке.

## Установка стабильной версии 0.3.0

Выберите один способ установки, чтобы избежать дублирования навыка.

Скачайте [установочный архив 0.3.0](https://github.com/tsvetaeff-den/ai-ready-sites/releases/download/v0.3.0/ai-ready-sites-0.3.0.zip), проверьте его по инструкции ниже, распакуйте и откройте каталог `ai-ready-sites`. Затем выполните:

```text
node scripts/install.mjs
```

Другой вариант — клонировать конкретный стабильный релиз и установить его:

```sh
git clone --branch v0.3.0 --depth 1 https://github.com/tsvetaeff-den/ai-ready-sites.git
cd ai-ready-sites
node scripts/install.mjs
```

Установщик копирует `skills/ai-ready-sites` в пользовательскую папку навыков Codex. Откройте новый чат или сеанс Codex и напишите:

> Используй $ai-ready-sites, чтобы создать сайт по этому заданию.

### Копирование папки без Node.js

Скопируйте всю папку `skills/ai-ready-sites` из пакета в пользовательскую папку навыков Codex:

- По умолчанию: `~/.codex/skills/ai-ready-sites`
- Windows: `%USERPROFILE%\.codex\skills\ai-ready-sites`
- Если задан собственный `CODEX_HOME`: его подпапка `skills/ai-ready-sites`

Сохраните все руководства, скрипты, лицензии и уведомления об использованных сторонних материалах вместе с `SKILL.md`. Если папка назначения уже существует, сначала сохраните её за пределами активной папки навыков. Не перезаписывайте установку, не относящуюся к этому пакету. После копирования откройте новый чат или сеанс Codex.

### Поведение и параметры установщика

Запускайте установщик из корня распакованного пакета или репозитория. Он ничего не скачивает и не требует npm-зависимостей. Он проверяет скопированные файлы и не меняет аккаунты, настройки MCP или глобальные инструкции.

| Ситуация или параметр | Результат |
| --- | --- |
| Навык ещё не установлен | Копирует навык и сообщает `INSTALLED` |
| Уже установлены идентичные файлы | Ничего не меняет и сообщает `ALREADY_INSTALLED` |
| Установленные файлы отличаются | Останавливается без их замены |
| `--replace` | Заменяет отличающиеся файлы, сохраняя резервную копию вне папки навыков; путь к копии указан в результате |
| `--skills-dir DIRECTORY` | Использует явно заданную родительскую папку навыков вместо стандартной |
| `--help` | Показывает справку без установки |

`--skills-dir` удобно использовать для отдельного тестового профиля. Этот параметр только задаёт место копирования файлов; приложение нужно настроить так, чтобы оно находило навык в этой папке.

## Тексты и документация

В навык входят три внутренних руководства: [редактирование и перевод](skills/ai-ready-sites/references/editorial.md), [техническая документация](skills/ai-ready-sites/references/technical-writing.md) и [тексты сайтов и интерфейсов](skills/ai-ready-sites/references/site-copy.md). Они позволяют работать только с текстом, без обязательной сборки сайта или проверки дизайна. Команды, факты о продукте и реальные названия элементов интерфейса необходимо сохранять и сверять с исходными материалами.

### Приложения с поддержкой плагинов

Корневой `plugin.json` — переносимый манифест Agent Plugins. Файл `.codex-plugin/plugin.json` содержит совместимый с Codex манифест того же плагина. Если ваше приложение поддерживает импорт локальных плагинов или подключение через каталог, можно выбрать этот способ вместо копирования навыка. Пакет содержит один плагин и не содержит собственного каталога плагинов.

Прямая установка папки навыка — проверенный способ с минимумом зависимостей. Импорт плагина нужно отдельно проверить в выбранном приложении. Не устанавливайте плагин и папку навыка одновременно в один профиль.

## Проверка стабильного архива

Скачайте `ai-ready-sites-0.3.0.sha256` со страницы того же [релиза 0.3.0](https://github.com/tsvetaeff-den/ai-ready-sites/releases/tag/v0.3.0). Поместите ZIP-архив и файл контрольной суммы в один каталог.

- Linux: `sha256sum -c ai-ready-sites-0.3.0.sha256`
- macOS: `shasum -a 256 -c ai-ready-sites-0.3.0.sha256`
- Windows PowerShell: выполните `Get-FileHash .\ai-ready-sites-0.3.0.zip -Algorithm SHA256` и сравните хеш с файлом контрольной суммы.

Хеши должны совпадать. Если они различаются, не устанавливайте этот архив. ZIP-архив релиза содержит один каталог `ai-ready-sites/` с навыком, установщиком, документацией и лицензиями.

## Примеры запросов

Укажите `$ai-ready-sites`, задачу и её границы:

- Создай небольшой сайт для этого продукта. Используй предоставленные факты, адаптивную вёрстку и работающее основное действие.
- Улучши эту панель управления, сохранив её компоненты и поведение.
- Исправь только наложение мобильного меню и проверь затронутое поведение.
- Проведи аудит сайта, не меняя файлы. Отдели наблюдаемые проблемы от гипотез.
- Проверь, готов ли этот сайт к выпуску. Не публикуй его.

Для работы с текстами и документацией можно также обратиться с такими задачами:

- Улучши этот README и переведи его на естественный русский язык. Сохрани команды, ссылки, сведения о версиях и ограничения.
- Перепиши текст этого лендинга, используя только предоставленные факты о продукте.
- Сверь эту инструкцию по настройке с реализацией и сообщи обо всём, что не удалось проверить.

## Состав пакета и границы действий

Пакет предоставляет один автоматически обнаруживаемый навык. По мере необходимости он загружает внутренние руководства по постановке задачи и UX, визуальному направлению, реализации, анимации, доступности, производительности, SEO, проверкам в браузере, DevTools, Playwright и завершению работы. В пакет также входят три руководства по текстам, перечисленные выше.

Необязательные утилиты диагностики и базовой браузерной проверки используют существующие инструменты и не устанавливают программы. В пакете нет MCP-сервера, хуков, учётных данных, телеметрии, автоматического обновления или удалённого сервиса. Приложение и модель могут использовать сетевые сервисы в соответствии со своими настройками.

Запрос на аудит не разрешает правки. Создание сайта или проверка готовности к выпуску не разрешает публикацию, реальную отправку форм, подключение платных сервисов или изменения в рабочей системе.

## Переход с 0.1.0

Версия 0.1.0 предоставляла семь отдельных навыков. Начиная с 0.2.0 их возможности объединены в `$ai-ready-sites` и внутренних руководствах; добавлены материалы по качеству и браузерным проверкам. Старые имена специализированных команд больше не предоставляются.

Сохраните старый пакет как резервную копию вне каталогов, где приложение ищет активные навыки. Установка обеих версий может привести к пересечению автоматического выбора. Существующие проекты и документы переносить не нужно. Пакет не зависит от личного website-workflow и не меняет его; явно указывайте `$ai-ready-sites`, если выбираете этот навык через существующий координатор.

## Проверки и ограничения

Из корня пакета выполните `node scripts/validate.mjs` для проверки целостности пакета и `node scripts/test-install.mjs` для проверки поведения установщика в изолированном окружении. Команда `node scripts/check-text-artifacts.mjs` сравнивает сохранённые результаты редактуры RU/EN, а также команды и ссылки в README. Эти проверки не запускают модель и не подтверждают смысловую эквивалентность, удобочитаемость или качество сайта. Сверка исходных и итоговых текстов описана в [отчёте о редакторской проверке](tests/editorial/REVIEW.md).

В [VALIDATION.md](VALIDATION.md) записаны проведённые проверки и их ограничения, в [tests/SCENARIOS.md](tests/SCENARIOS.md) — поведенческие сценарии, в [CONTRIBUTING.md](CONTRIBUTING.md) — информация для разработки, а в [SECURITY.md](SECURITY.md) — порядок сообщения о проблемах безопасности. Запуск workflow относится к указанному в нём коммиту. Он проверяет пакет, установщик и сохранённые текстовые результаты; качество сайта требует отдельных проверок.

## Лицензия и источники

Оригинальные материалы распространяются по Apache-2.0. Для адаптированных сторонних материалов сохранены соответствующие уведомления в [THIRD_PARTY_NOTICES.md](skills/ai-ready-sites/THIRD_PARTY_NOTICES.md) и [upstreams.lock.json](skills/ai-ready-sites/upstreams.lock.json). Это независимый пакет AI-Ready, а не официальная сборка, одобренная авторами исходных материалов. Бинарные файлы сторонних проектов и браузерные библиотеки не распространяются в составе пакета.
